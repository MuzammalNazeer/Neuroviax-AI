## 💡 Executive Summary & Core Philosophy

Traditional ERP and business management platforms operate on a **retrospective model**:
$$\text{Record Data} \longrightarrow \text{Generate Reports} \longrightarrow \text{Human Tries to Decide Alone}$$

This fails SME owners who lack the time or analytical staff to interpret complex dashboards. **Neuroviax ABOP reframes the entire operating paradigm**:
$$\text{Record} \longrightarrow \text{AI Analyzes} \longrightarrow \text{AI Recommends} \longrightarrow \text{Human Approves (1-Tap)} \longrightarrow \text{Workflow Executes Automatically}$$

Every business signal (stock movement, sales invoice, overdue payment, supplier cost change) triggers autonomous background analysis with explainable reasoning and confidence metrics.

## 🤖 The 6 Domain-Scoped AI Copilots

Rather than a generic, error-prone chatbot, Neuroviax deploys **6 domain-constrained AI assistants**:

```
                          ┌────────────────────────┐
                          │   Operational Signals  │
                          └───────────┬────────────┘
                                      │
         ┌────────────┬───────────────┼───────────────┬────────────┐
         ▼            ▼               ▼               ▼            ▼
   ┌───────────┐┌───────────┐   ┌───────────┐   ┌───────────┐┌───────────┐
   │   Sales   ││Procurement│   │ Inventory │   │  Finance  ││ Marketing │
   │ Assistant ││ Assistant │   │ Assistant │   │ Assistant ││ Assistant │
   └───────────┘└───────────┘   └───────────┘   └───────────┘└───────────┘
         │            │               │               │            │
         └────────────┴───────────────┼───────────────┴────────────┘
                                      │
                         ┌────────────▼────────────┐
                         │  Support & WhatsApp AI  │
                         └─────────────────────────┘
```

1. 🛒 **Procurement Assistant**:
   - Calculates dynamic inventory velocity and lead times.
   - Generates reorder recommendations with confidence scores and supplier price trend comparisons.
2. 📈 **Sales Intelligence Assistant**:
   - Analyzes customer purchase frequency and basket mix.
   - Suggests next-best-offers, personalized promotions, and flags churning clients.
3. 📦 **Inventory Optimization Assistant**:
   - Real-time stock alerts, shrinkage anomaly detection, dead-stock warnings, and reorder threshold adjustments.
4. 💳 **Finance & Cash-Flow Assistant**:
   - Generates 30-day forward cash-flow forecasts.
   - Categorizes operating expenses and flags anomalous ledger discrepancies.
5. 🎯 **Marketing Assistant**:
   - Automated customer segmentation (VIP, At-Risk, Inactive).
   - Generates targeted campaign copy and WhatsApp promotional broadcasts.
6. 🎧 **Customer Support & WhatsApp Assistant**:
   - Omnichannel communication hub.
   - Drafts automated order confirmations, dispatch updates, and support inquiry replies via WhatsApp.

## 🛡️ Risk-Tiered Autonomy Model (Human-in-the-Loop)

Safety is foundational. AI suggestions are categorized into **three strict risk tiers** to prevent unauthorized business actions:

```
┌────────────────────────────────────────────────────────────────────────┐
│                     RISK-TIERED AUTONOMY MATRIX                        │
├───────────┬───────────────────────────────┬────────────────────────────┤
│ Risk Tier │ Action Criteria               │ Autonomous Execution Model │
├───────────┼───────────────────────────────┼────────────────────────────┤
│ 🟢 LOW    │ Confidence > 85%, Low Value   │ Autonomous execution;      │
│           │ (e.g., Stock alerts, draft PO)│ instant owner notification.│
├───────────┼───────────────────────────────┼────────────────────────────┤
│ 🟡 MEDIUM │ Pre-configured bounds         │ Executes within policy;    │
│           │ (e.g., Send payment reminders)│ owner can override 24/7.   │
├───────────┼───────────────────────────────┼────────────────────────────┤
│ 🔴 HIGH   │ Financial risk, High-value PO,│ BLOCKED until explicit     │
│           │ Bulk pricing changes, refunds │ 1-tap human approval.      │
└───────────┴───────────────────────────────┴────────────────────────────┘
```

## 📦 Complete System Architecture & Modules

### Operational Modules
- **Authentication & RBAC**: JWT Access & Refresh token rotation, multi-business tenancy, and granular permissions (`Owner`, `Admin`, `Manager`, `Staff`).
- **Product Master Catalog**: Centralized SKU directory, barcode scanner readiness, multi-tier pricing, cost tracking, and stock units.
- **Multi-Branch Inventory**: Warehouse receiving, shelf picking, inter-branch stock transfers, and automated low-stock warnings.
- **Unified Orders**: Single polymorphic schema handling both Sales Orders (B2C/B2B) and Purchase Orders (procurement) through a full lifecycle (`draft → pending → approved → fulfilled → cancelled`).
- **Payments & Treasury**: Multi-gateway payment records (Stripe, JazzCash, Easypaisa, Cash on Delivery, Bank Transfer) with real-time balance sheets.
- **Expense Tracking**: Categorized overhead, operational expenditures, and supplier payments.
- **CRM & Vendor Management**: Comprehensive directories for Customers and Suppliers with credit terms, ledger balances, and order histories.
- **Integrations Hub**: Webhook listeners, Stripe billing sync, and WhatsApp Business API connectors.
- **Tamper-Evident Audit Logging**: Immutable record capturing every critical business event, user ID, IP address, and timestamp.

## 🚀 Quick Start & Local Installation

### Prerequisites
- **Node.js** (v18.x or higher)
- **npm** (v9.x or higher)
- *(Optional)* **MongoDB** (A local or cloud MongoDB instance; the application automatically falls back to an **In-Memory database** if no MongoDB URI is supplied).

### 1. Clone the Repository
```bash
git clone https://github.com/MuzammalNazeer/Neuroviax-AI.git
cd Neuroviax-AI
```

### 2. Backend Setup
```bash
cd backend
npm install
npm run dev
# Server starts on http://localhost:5000
```

### 3. Frontend Setup
Open a new terminal:
```bash
cd frontend
npm install
npm run dev
# Application opens on http://localhost:5173
```
