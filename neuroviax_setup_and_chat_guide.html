2. Step-by-Step Local Environment Setup

Step 2.1: Prerequisites

  • Node.js: v18.x or v20.x LTS installed (Verify with node -v)
  • npm: v9.x or v10.x installed (Verify with npm -v)
  • Git: Recommended for version control
  • Operating System: Windows 10/11, macOS, or Linux

Step 2.2: Backend Configuration & Execution

Open Terminal 1 and navigate to the backend folder:

cd neuroviax-mern/backend
npm install

Verify or create the environment file backend/.env:

PORT=5000
NODE_ENV=development
USE_IN_MEMORY=true
MONGO_URI=mongodb://127.0.0.1:27017/neuroviax
JWT_ACCESS_SECRET=neuroviax_super_secret_jwt_key_2026
JWT_REFRESH_SECRET=neuroviax_super_refresh_jwt_key_2026
JWT_ACCESS_EXPIRES=15m
JWT_REFRESH_EXPIRES=7d
CLIENT_URL=http://localhost:5173
Zero-Configuration Database (In-Memory Mode):
Notice USE_IN_MEMORY=true. You do not need to install or run MongoDB locally! The backend automatically spins up an in-memory database with pre-seeded store inventory, orders, products, and customers.

Start the backend API server:

npm run dev

Expected output: [INFO] USE_IN_MEMORY is set to true... Server running in development mode on port 5000.

Step 2.3: Frontend Configuration & Execution

Open Terminal 2 and navigate to the frontend folder:

cd neuroviax-mern/frontend
npm install
npm run dev

To run both 5173 (Website) and 5175 (Admin Cockpit), the project includes the dual-server script in package.json:

"scripts": {
  "dev": "concurrently \"vite --port 5173\" \"vite --port 5175\"",
  "build": "tsc -b && vite build"
}

3.1 Demand Forecasting (XGBoost / LightGBM Regressor)

Built with Gradient Boosted Decision Trees (GBDT), this engine computes residuals across sequential decision stumps to counteract retail volatility:

  • Feature 1 (Sales Velocity): Rolling 7-day, 14-day, and 30-day moving averages.
  • Feature 2 (Trend Slope): Acceleration gradient $\Delta y / \Delta t$ comparing the last 14 days against the prior period.
  • Feature 3 (Calendar Seasonality): Monthly curve (0.92x to 1.30x) and day-of-week retail surges (Weekend multipliers up to 1.40x).
  • Feature 4 (Safety Stock Buffer): Standard deviation $\sigma$ with a $Z=1.65$ safety stock factor (95% service level).
  • Feature 5 (Stockout Warning): Computes exact stockout countdown date: $$Days = \frac{\text{Current Inventory}}{\text{Adjusted Daily Demand}}$$

3.2 Time-Series Forecasting (Deep Learning LSTM Recurrent Neural Network)

Engineered in backend/utils/lstmForecaster.js, this recurrent model retains long-term dependencies:

  • Hidden Units: 16 recurrent memory cells with input, forget, and output gates.
  • Activation Functions: Sigmoid gate activations ($\sigma$) combined with Hyperbolic Tangent ($\tanh$) cell states.
  • Autoregressive Rollout: Recursive rollout across $T+1$ through $T+30$ time steps.

3.3 Collaborative Filtering Recommendation Engine

Engineered in backend/utils/collaborativeFiltering.js, this engine uses Item-Based Collaborative Filtering to generate personalized recommendations:

  • User-Item Matrix: Maps each customer $u$ to purchased products $i$ with weighted order frequency.
  • Cosine Similarity Formula: $$\text{Similarity}(A, B) = \frac{\sum_{u} R_{u,A} \cdot R_{u,B}}{\sqrt{\sum_{u} R_{u,A}^2} \cdot \sqrt{\sum_{u} R_{u,B}^2}}$$
  • Co-Purchase Analysis: Identifies items frequently bought together in the same transaction.

3.4 Sales Prediction & Revenue Forecast (Multi-Source Fusion)

Synthesizes the three fundamental business dimensions into monetary cash-flow projections:

  • Sales Stream: 30-day baseline consumption and momentum gradient.
  • Customer Stream: Active buyers count and cohort repeat buying rate.
  • Product Stream: Selling price, cost price, and gross margin elasticity.
  • Financial Output: $$\text{Projected Revenue} = \text{Forecasted Units} \times \text{Selling Price}$$ $$\text{Projected Gross Profit} = \text{Forecasted Units} \times (\text{Selling Price} - \text{Cost Price})$$

6. Troubleshooting & Operational FAQs

Q1: What if Port 5000, 5173, or 5175 is already occupied?

Run PowerShell as administrator and kill the occupying process: 

# Find PID on port 5000
Get-NetTCPConnection -LocalPort 5000 | Select-Object OwningProcess
# Terminate process
Stop-Process -Id <PID> -Force

Q2: How do I switch from In-Memory DB to a Production MongoDB Atlas cluster?

In backend/.env, set USE_IN_MEMORY=false and provide your MongoDB connection string: 

USE_IN_MEMORY=false
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/neuroviax?retryWrites=true&w=majority

Q3: How do I access the Super Admin Cockpit?

Open your browser and navigate directly to: http://localhost:5175/. The application recognizes port 5175 and loads the Super Admin Decision Cockpit with real-time system metrics, model architectures, and tenant management.
